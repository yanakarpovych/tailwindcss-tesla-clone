# Tesla Landing Page

A responsive Tesla-inspired landing page built with HTML and Tailwind CSS.

## Live Demo

[View Live Demo](https://yanakarpovych.github.io/tailwindcss-tesla-clone/)

## Overview

This project is a front-end recreation of a Tesla-style landing page, focusing on clean layout, modern design, and responsive styling.

## Features

- Responsive page layout
- Tesla-inspired visual design
- Navigation section
- Product-focused content
- Tailwind CSS utility-based styling

## Technologies

- HTML5
- Tailwind CSS

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/yanakarpovych/tailwindcss-tesla-clone.git
   ```

2. Open `index.html` in your browser.
